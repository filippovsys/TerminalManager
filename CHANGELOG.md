# Terminal Manager -- журнал версий

Версия хранится в `config.APP_VERSION` и автоматически пишется в таблицу
`app_version_log` при каждом запуске программы (`database.log_app_version_if_new`,
вызывается из `main.py`). Смотреть историю прямо из программы: меню
"Справка -> История версий...". При каждой значимой доработке -- поднимать
`APP_VERSION` в config.py и дописывать сюда пункт.

## 1.0
- Черновая схема БД (`db_schema.sql`) и анализ исходного Excel-файла.

## 1.1
- Импорт данных из Excel в SQLite (`import_excel.py`).
- Первая версия GUI: логин, поиск, карточка терминала, карточка мерчанта.

## 1.2
- Главный экран переработан: слева вкладки "Активные" / "Склад" / "E-POS".
- "Активные" -- список как раньше в Excel (одна строка = один активный
  платёжный ID), сгруппирован по типу клиента BANK -> EDARA -> TELEKEÇI,
  сквозная нумерация, фильтр по типу, панель подробностей справа
  (ID, M/id, модель, S/N, SIM, IP, тип, транз/счёт, расчётный счёт).
- Сводка наверху считается по текущей открытой вкладке, а не по всей базе.
- Новое действие "Закрыть ID": отвязывает платёжный ID от терминала (доступно
  и с главного экрана, и из карточки терминала). Если это была последняя
  активная привязка -- терминал автоматически уезжает на склад, с фиксацией
  кто и когда это сделал.
- В `terminal_ids` добавлены поля: адрес, телефон, дата установки, дата
  выдачи, расчётный счёт (пока пустой -- заполняется вручную по мере надобности).
- Управление пользователями (меню "Администрирование -> Пользователи"):
  создание, смена пароля, смена роли, архивация ("удаление" без потери
  истории и связей в audit_log) и восстановление из архива.
- Исправлена вставка через Ctrl+V (и Ctrl+C/X/A) во всех полях ввода --
  раньше не работала при русской раскладке клавиатуры Windows (`gui/utils.py`).
- Автоматическая догонка схемы уже существующей БД до новой версии
  (`database.ensure_schema_upgrades`) -- при обновлении программы не нужно
  пересоздавать или переимпортировать базу, как раньше было с HalkAssetsGUI.

## 1.3
- Полноэкранный запуск главного окна.
- Вкладки "Активные" / "Склад" / "Списанные" / "E-POS" под сводкой (как листы Excel).
- Дерево на вкладке "Активные": Тип клиента -> Физический терминал -> ID,
  как в исходном Excel (столбец SAN).
- Сводка по терминалам и ID, сквозная нумерация терминалов.
- Сортировка ID и терминалов по дате выдачи.
- Фильтры: тип клиента, модель, собственность, регистронезависимый поиск
  (в т.ч. по кириллице).
- Настройка колонок (порядок, видимость, ширины) — сохраняется в JSON.
- Двойной клик по ID — редактирование; по терминалу — карточка.
- Правый клик по строке — контекстное меню с действиями.
- Выдача нового ID с автозаполнением по существующему M/id и S/N
  (создание новых мерчантов и терминалов "на лету").
- Редактирование ID: смена мерчанта, перепривязка/отвязка терминала.
- Диалог ремонта с кнопками "Отправить / Вернулся сегодня".
- Защита от повторного списания и от пустой БД.
- Версия схемы в самой БД (schema_version).
- Экспорт текущей вкладки в Excel с сохранением структуры дерева.
- Массовые операции: закрыть выбранные ID / переместить выбранные терминалы.
- Отчёт по клиенту (активные, все ID, терминалы, история).
- Отчёт по моделям терминалов + экспорт в Excel.
- Тег версии при upload.bat.
